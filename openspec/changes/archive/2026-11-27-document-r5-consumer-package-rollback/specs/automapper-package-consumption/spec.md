# 消费者独立演练公开包回退

## ADDED Requirements

### Requirement: 普通消费者可用公开材料验证映射补丁回退

消费者指南 SHALL 让固定模板的维护者只用指南、匿名可取得的源码和发行物，以及自己的工具、凭据和专用 SQL Server，完成 `net10.0` 上的 R4 → R5 → R4 同库演练。验收记录须标明所用指南的 SHA-256、实际运行的两个入口和逐阶段结果。

#### Scenario: 从干净目录切回自行保存的旧版

- **WHEN** 读者在干净目录分别从空缓存构建公开 R4 与 R5，保存 R4 的 Web.Host 与 Migrator。R4 在专用空库完成首次迁移并创建 A。R5 在同库查回 A、创建 B 并查回 B，然后停止 R5 Host
- **THEN** 两版的 Web.Host 各 13 个、Migrator 各 10 个维护包均与公开签后下载的版本、摘要一致。两个入口输出的三份映射 DLL 均可追溯到所选包成员。核对首段保存的 R4 输出后，直接从原目录依次运行 Migrator 和 Web.Host
- **AND** 三阶段的实例与数据库身份相同。以 R4 首次迁移后的 30 个迁移 ID 为基线，后两阶段各自的迁移前后均与基线逐项一致
- **AND** 末段取得同一租户管理员的一次新认证，两次授权查询分别唯一命中 A、B。各自响应的 ID、用户名对应本人的创建回执，业务字段对应创建时提交的值。租户身份由认证会话和对应用户的数据库行核实

#### Scenario: 启动前发现回退输入不符

- **WHEN** 包源或签后摘要不符、保存的 R4 输出与清单不符，或两入口的实际连接偏离隔离库
- **THEN** 在受影响阶段启动 Migrator 和写入业务前停止，指出入口或文件及预期与实际值。独立验收用 R4 运行目录的副本替换一个映射 DLL，保留校验失败、迁移未启动和业务未写入的结果

#### Scenario: 创建成功后授权查询失败

- **WHEN** R5 创建 B 已返回 ID，随后对 B 的查询失败、返回多条或查到了其他用户
- **THEN** 保留 B 的创建回执、此前 A 的读回结果，以及 B 的查询和数据库读回结果或缺项。登记 R5 失败、末段 R4 未执行，本轮独立演练未通过

#### Scenario: 回退后只查回一名用户

- **WHEN** 已切回保存的 R4，查询 A 成功，查询 B 未唯一命中与 B 创建回执相符的记录
- **THEN** 分别记录两次查询结果，保留两份创建回执和可取得的数据库读数，登记末段 R4 失败

#### Scenario: 指南步骤需要现场补充

- **WHEN** 读者必须使用发布者私有输入或指南以外的命令，才能完成任一阶段
- **THEN** 记录缺项，补齐公开步骤。修订后的指南以新摘要从干净目录和新的专用空库复验，成功路径与启动前停止检查均通过后才能登记独立消费者验收通过
