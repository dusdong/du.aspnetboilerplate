# 消费者回退指南与实跑任务

## 1. 写出可独立执行的路径

- [x] 1.1 编写 `docs/maintenance/r5-consumer-package-rollback.md`。从固定模板和新建专用空库准备 R4，给出分目录构建两版、按两份公开附件核对 Web.Host 13 个与 Migrator 10 个维护包及三个映射 DLL、保存和校验 R4 运行产物的命令。列明工具、公开输入和读者自行生成的文件。
- [x] 1.2 写明每次切换时停止旧 Host、核实两入口连接与数据库身份、运行 Migrator、再启动目标 Host 的顺序。给出 R4 创建 A、R5 查 A 并创建和查回 B、保存的 R4 一次新认证后分别查 A 和 B 的命令与断言。写清迁移 ID 基线、逐人回执、失败停止位置和备份恢复的写入边界。

## 2. 独立消费与交付

- [x] 2.1 按同一摘要的指南从干净目录和专用空库执行三阶段。保留两次构建的包图与签后摘要、三阶段启动目录与进程、同库及迁移历史对照、会话身份及逐人 API 与 SQL 结果。另取保存的 R4 输出副本，替换一个映射 DLL，验证校验报告差异并在迁移与写入前停止。
- [x] 2.2 将指南摘要、环境、实际命令、退出码和各阶段结果登记在主仓。失败时保留创建回执和逐人查询结果，标明尚未执行的步骤。若修订指南，用新摘要重跑 2.1。同库演练成功且替换 DLL 的副本按预期停止后，从文档索引与模板手册链接已验指南，标明本次 API 范围及历史 Angular、备份恢复证据。检查链接并执行 `openspec-cn validate --all --strict --no-interactive`。
