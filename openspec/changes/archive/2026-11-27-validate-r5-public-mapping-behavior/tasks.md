# 公开映射包消费对照任务

## 1. 准备可公开复跑的业务消费者

- [x] 1.1 在主仓为现有业务探针补充公开 R4、R5 的运行入口与用法，沿用旧入口的默认值。为两侧固定模板、环境、包源和精确依赖，接入签后摘要、还原图与所选资产核对。在副本中给出错误摘要，验证入口返回非零并指出相应版本和包，保留原始输出，并运行受影响的历史入口回归。
- [x] 1.2 将同一份用户更新、按键集合及 SQLite 投影断言接入两个独立进程，将目标用户的 `IsActive` 设为 `false`，验证其按 DTO 更新为 `true`。逐项登记期望，覆盖缺项和两侧同错。单侧反例只交换第一侧预期列中的两列，运行两个真实探针，核对第一侧前两项结果及投影失败时的 SQL、参数、实际列、表达式和物化行均可回读，第二侧三项通过，总入口返回非零。正式业务结论由 2.1 的原始输入给出。

## 2. 执行两版对照并交付实测结果

- [x] 2.1 按文档分别从空缓存还原、Release 构建并运行两版，核对四条精确依赖、实际加载的三份映射 DLL 和唯一引擎实例。保留运行命令、退出码、两张真实包图、对象引用断言、执行 SQL、参数、投影表达式及物化结果。逐项对照既定预期。一侧业务断言失败时保留已取得的结果并标明未执行项，另一侧独立完成，最后汇总两侧退出码。
