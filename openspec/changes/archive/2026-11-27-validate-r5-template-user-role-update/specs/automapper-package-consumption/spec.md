# Spec Delta

## ADDED Requirements

### Requirement: 两代公开映射包可对照固定模板的用户角色更新提交

验收入口 SHALL 让消费者用两代公开映射包在同一固定模板与 SQL Server 组合上运行真实用户更新 API，逐版核对直接分配给目标用户的角色是否按预期保留、替换或清空，同时核对普通字段更新及创建时间保留。角色范围以 `user.Roles` 和 `dbo.AbpUserRoles` 的直接关联为准。组织单元继承角色和最终权限超出本项验收范围。

#### Scenario: 两代在可比的独立输入上启动

- **WHEN** 在固定模板、平台、SDK、目标框架、实际共享运行时和 SQL Server Provider 版本上分别准备公开 R4 与 R5
- **THEN** 两代使用独立空 NuGet 缓存、Release 输出、Host 进程和专用 SQL Server 测试库。逐版核对实际还原、签后维护包摘要和 Host 加载的映射资产，非映射依赖在同一入口间一致
- **AND** 两侧以等价种子启动。各自使用目标租户的授权管理员建立两枚无业务授权的非管理角色 A、B 和一名初始仅有 A 的普通用户。API 与 SQL 共同确认该用户及初态

#### Scenario: 显式空值保留原角色

- **WHEN** 管理员对目标用户发送 `PUT User/Update`，在请求 JSON 中明确提交 `roleNames: null`
- **THEN** 直接分配给该用户的角色仍只有 A

#### Scenario: 单元素数组替换角色

- **WHEN** 角色 A 的阶段通过后，管理员更新同一用户并提交只含 B 的 `roleNames` 数组
- **THEN** 直接分配给该用户的角色只有 B，与 A 的直接关联已移除

#### Scenario: 空数组清空角色

- **WHEN** 角色 B 的阶段通过后，管理员更新同一用户并提交 `roleNames: []`
- **THEN** 响应的角色数组为空，`dbo.AbpUserRoles` 中该用户的直接关联为零行

#### Scenario: 每步更新可独立核对提交

- **WHEN** 管理员在任一步更新中同时提交该步约定的普通字段及有别于原值的 `creationTime`
- **THEN** 更新回执和独立的 `GET User/Get` 按 ID 读回均对应原目标用户，普通字段取该步输入，创建时间保留各自库的初值，角色数组精确匹配阶段预期
- **AND** PUT 与独立 GET 各自具有唯一请求标识，可分别追溯到实际 Host PID、目标用户 ID，以及处理该用户的业务命令在其连接上实测的 SQL Server 实例与库名，按实测实例与库名核对当前数据库 ID、GUID 与该侧预检记录一致
- **AND** 只读 SQL 在各侧实际使用的库核对同一用户 ID、租户、普通字段、原创建时间与完整角色关系。角色按同库的 ID 和角色名对应，跨侧比较业务身份和时间不变量

#### Scenario: 请求缺少可信的业务连接证据

- **WHEN** PUT 或独立 GET 的实际业务连接无法与该请求及目标用户关联，或实测实例和库名与该侧预检身份不符，包括匹配到另一侧库的情况
- **THEN** 报告标明该侧、请求和缺失或失配的身份，判定输入不可比，停止该侧后续写入。即使配置、返回字段或独立 SQL 的值符合预期，本侧仍无法通过。已核实输入的另一侧继续验收，总入口返回非零

#### Scenario: PUT 已发出但回执不可用

- **WHEN** 更新请求已经发出，因超时、断连或响应无法解析而缺少可核对的 PUT 回执
- **THEN** 该步失败，保留脱敏请求、错误和已收到的响应内容。停止该侧写入，不重发 PUT，后续依赖步骤标记未执行
- **AND** 目标库身份可核实时，使用已知用户 ID 另发独立 GET 并执行只读 SQL，分别记录实测值或无法取得的原因。目标库身份无法核实时，两份诊断读回均标记未执行并记录原因。即使两份读回均符合预期，回执仍计为缺失，另一侧继续独立验收，总入口返回非零

#### Scenario: 输入不合格或阶段结果偏离预期

- **WHEN** 发行、运行环境、数据库或初态等比较前提无法核对，或一侧或两侧的业务阶段失败、缺失或未执行
- **THEN** 总验收返回非零，按版本和阶段给出预期、实测、已有提交证据及未执行步骤，区分输入不可比、单侧失败和两侧失败。已验证前提的另一侧仍独立执行
- **AND** 若两侧出现同一偏差，两侧各自的阶段均失败。只有输入可比且两侧三步分别满足各自预期，才登记固定组合的业务对照通过
