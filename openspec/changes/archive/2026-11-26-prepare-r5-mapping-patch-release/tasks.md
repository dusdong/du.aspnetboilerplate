# 三包发行准备任务

## 1. 确认版本和制备来源

- [x] 1.1 主仓核定拟用主仓 tag 名，核对该 tag、三个 NuGet 版本、十个沿用包、原批次摘要和三个生产 gitlink，登记查询日期、已占用目标的归属或冲突。以原件运行三包离线核验，保存可定位的结果。
- [x] 1.2 将公开安装说明纳入 AutoMapper 子仓新提交，从该干净提交用 `pack-r3-engine.sh --r5` 制备引擎主包及匹配符号。解包核对 ID、版本、命令、包源、维护入口及 MIT 署名。登记打包提交、Git 树和 `RepositoryCommit`，核对 `source-commit.txt` 及 nuspec 的 `repository/@commit`，逐成员对照原归档并记录实际差异。

[版本核对与引擎实物记录](source-and-engine-validation.md)

## 2. 冻结待发组合并验收

- [x] 2.1 主仓核对 Collection 与框架适配器的编译来源、四条精确依赖和调试符号，按实际差异选择沿用或重新制备。冻结三对待发件、新清单和独立摘要，验证同名替换件会被拒绝，原 R5 批次仍可离线复核。
- [x] 2.2 从隔离空缓存消费待发组合，核对独立消费者实际加载的程序集、普通映射、按键集合与投影。将引擎专项、两代 Web.Host 与 Migrator 的资产检查及受变化影响的业务复验逐项关联到待发件。列明引用历史运行的输入对应关系和实测边界。

[三包待发批次与复跑记录](source-and-engine-validation.md#三包待发批次) · [待发组合独立消费与模板验收](consumption-validation.md)

## 3. 演练回读与交接

- [x] 3.1 演练回读核验、续作与纯 nuget.org 消费。
  - 保留 R4 首发的 26 份归档和 18 个符号目标核验，接入 R5 六份归档和三个 PDB 目标。用 R4 已签名实物走真实验签路径，演练内容冲突、符号待索引及部分受理后重跑。
  - 引擎与 Collection 已验时，分别验证 `Du.Abp [10.5.1]` 沿用证据缺失、摘要不符均暂停适配器，补正后从原状态续作，上传队列始终仅含三个新包。日志逐包记录放行或暂停的依据。
  - 保留 R4 历史路径和 R5 候选混合源模式。用 R4 已签名实物和隔离样本执行将交付的同一条 R5 纯 nuget.org 消费命令，记录正确输入通过、混入本地源或错误批次被拒绝的结果。
- [x] 3.2 交付本地待发批次和发行步骤。
  - 交付安装与发行说明草案、六份归档摘要、上传顺序及已演练的公开消费命令。登记拟用 tag 名、目标主仓提交和 `git ls-tree` 查得的三个生产 gitlink。
  - 主仓尚未固定新引擎时，记录实际 gitlink 与新打包提交及源码树的准确差异，标记 tag 目标待定。列出打 tag 前确认子仓提交可取得、固定新 gitlink 和回读最终主仓提交的待办。
  - 列出实际公开后才执行的验收。三个新主包匿名下载、验签与内容对账，三个服务端 PDB 回读，两代 Web.Host 与 Migrator 四入口空缓存纯 nuget.org 还原，以及隔离库新装与同库业务。GitHub Release 在公开验收通过并取得相应授权后发布。
  - 运行 R4 既有回归、适用的 R5 检查、链接核对和 OpenSpec 严格校验，给出发行或暂缓的建议。
