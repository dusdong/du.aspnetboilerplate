# core-package-consumption Specification

## Purpose

让维护者能从一批明确的核心候选 NuGet 包重现独立后端的安装和运行结果，并按每个目标框架核查包来源、传递依赖、程序集兼容性以及真实数据库操作的证据。

## Requirements

### Requirement: 五个核心项目可显式生成兼容候选包

框架 SHALL 提供仅覆盖五个已登记核心项目的显式候选打包入口。每批候选使用同一个预发布包版本并同时提供 `net9.0` 和 `net10.0` 资产。

#### Scenario: 从当前维护源码生成本地候选

- **WHEN** 维护者用明确版本从可追溯的框架输入生成候选
- **THEN** 得到五个已登记 `Du.Abp*` 包及对应符号包，实际包内记录 fork 仓库、源码来源、许可和图标，证据给出输入身份与产物摘要
- **AND** 每份框架 Release DLL 的 `TargetFrameworkAttribute` 与所在的 `lib/<TFM>` 目录对应
- **AND** `AssemblyName`、`RootNamespace`、程序集版本、公共及受保护 API 和清单资源与同目标 R1 基线一致

#### Scenario: 使用原有普通源码入口

- **WHEN** 源码调用方沿用原项目引用或运行常规构建与打包
- **THEN** 各项目沿用既有目标、程序集名、根命名空间、原有包身份及打包行为

### Requirement: 实际候选和还原资产的依赖闭包一致

主仓 SHALL 按目标框架核对实际候选包的 NuGet 声明及独立消费者的解析结果，且每个目标只解析到同一批五个维护版框架包。

#### Scenario: 从独立包缓存还原一个目标

- **WHEN** 一个目标从空包缓存还原，框架包锁定到本次候选源及版本，第三方包使用已登记的第三方源
- **THEN** 直接框架包仅为 `Du.Abp.AspNetCore` 和 `Du.Abp.EntityFrameworkCore`，两条三级链分别通过 `Du.Abp.Web.Common` 和 `Du.Abp.EntityFramework.Common` 到达同一份 `Du.Abp`
- **AND** 四条内部边均来自同目标的包依赖组，五个包的解析版本均为指定候选版本，实际编译及运行资产归属于相应包和目标，第三方依赖及来源可逐项核对
- **AND** 依赖图和实际输出中的每个框架程序集来源唯一

#### Scenario: 包缺失、被替换或引入错误依赖

- **WHEN** 候选缺包、版本或摘要不符、目标资产缺失、DLL 声明的目标框架与包内目录不符、解析混入原版或其他发行线框架包，或者框架程序集拥有多个来源
- **THEN** 验证返回非零并指出受影响的包、目标或资产；该次验证保留已取得的证据及未执行阶段

### Requirement: 独立后端执行真实工作单元并读回 SQLite

候选 SHALL 支持独立后端在受测系统上分别以 `net9.0` 与 `net10.0` 启动。消费者须经真实 HTTP 请求验证框架初始化、DI 和关系型数据持久化。

#### Scenario: 用两个请求跨工作单元验证写入和查询

- **WHEN** 从已核对的资产构建并启动目标应用，写入请求通过 ABP DI 解析业务服务，通过仓储写入一条已知记录。仓储使用的 `DbContext` 持有实际 SQLite 事务，负责该事务的 ABP 工作单元完成提交后，写入请求才返回成功
- **THEN** 独立读请求从新的 DI 作用域和工作单元经对应目标的 SQLite Provider 查出恰好该条记录，并可断言预期标识和值
- **AND** 验收记录可按写入请求核对活动事务及该工作单元成功提交的证据
- **AND** 实际加载的五个框架 DLL 与指定候选包相应目标的 DLL 摘要及程序集身份一致

#### Scenario: 宿主成功启动但业务证据缺失

- **WHEN** 宿主或探测命令返回成功，但缺少期望的 HTTP 响应、模块或 DI 证据、写入事务或工作单元成功提交的证据、独立请求的 SQLite 读回、框架程序集加载证据或任一目标的结果
- **THEN** 整体候选验收失败，报告保留实际的成功、失败和未执行范围

### Requirement: 验收结论对应实际候选和受测环境

主仓 SHALL 将验证结论关联到输入源码、实际候选包、目标框架、还原和运行环境以及可复核的证据路径。

#### Scenario: 两个目标均通过同批候选的验收

- **WHEN** 产物、依赖、程序集与真实消费的必需检查均成功
- **THEN** 验收记录给出候选源码身份、五个包的版本与摘要、两个目标的实际命令和退出码、平台架构、运行时及 Provider，支持结论限于实际验证的组合
